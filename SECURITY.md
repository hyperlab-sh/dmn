# Security Policy

## Supported versions

| Version | Supported |
| ------- | --------- |
| latest  | Yes       |

## Reporting a vulnerability

dmn reads your coding sessions and writes what it learns to a memory store. Anything that
could leak a secret into memory, inject text into an agent's context that the user did not
write, or let one project's memory reach another is a security issue.

Report it privately to **me@saulo.engineer** or through
[GitHub private vulnerability reporting](https://github.com/hyperlab-sh/dmn/security/advisories/new).
Do not open a public issue.

You can expect an initial response within 48 hours.
